# Stem Finder

Port coverage and capability finder for Stem Fuels - which fuel grades, which delivery method, which warehouse, and the desk that owns each port.

Live: https://becoded126.github.io/stemfuel-dashboard/

Independent spec-work demo by Brandon-Ray Brown, built from public data at stemfuels.com. Not affiliated with Stem Fuels. No pricing, stock levels or customer data.

64 locations across 23 countries and territories, 6 stocking warehouses, 11 desks.
